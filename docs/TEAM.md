## Git workflow

Start a task branch from the updated `main` branch. Keep each change focused and run `npm test` and `npm run build` before committing. Open a pull request for review when authorized. Leonardo reviews and merges changes. Lovable also syncs with `main`, so keep published commit history intact. [Project instructions](../AGENTS.md)

Use [Project context](../PROJECT_CONTEXT.md) and [Session handoff](../SESSION_HANDOFF.md) when transferring work between contributors. The [game design](GAME_DESIGN.md), [data sources](DATA_SOURCES.md), and [writing guide](STYLE_GUIDE.md) cover rules and content.
